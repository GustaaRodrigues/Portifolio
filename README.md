# ⚒️ Ferramentas utilizadas

## 🌐 HTML
<br>
Foi feito todo o esqueleto do site, incluindo: O menu de navegação, a seção inicial com foto, a apresentação, a lista de habilidades técnicas, os cards de projetos, a formação acadêmica e os links de contato. 
<br>
Foi muito utilizado botões que ajudavam na navegação pelo site, além de hiperlinks que facilitavam o acesso, por exemplo, ao GitHub e o Linkedin.
<br>

## 🖌️ CSS
<br>
Com o CSS, dei cor e vida ao esqueleto feito pelo HTML, definindo cores de acordo com tonalidades que ornavam com a minha de foto de perfil escolhida.
<br>

# 💭 Java Script
<br>
A parte mais simples do projeto, onde foi só implementado o modo escuro do site. Dando mais descanso visual ao leitor.
